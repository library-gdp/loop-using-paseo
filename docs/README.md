# 중앙 문서

이 디렉토리는 프로젝트의 **중앙 문서**를 담는다. 중앙 문서는 프로젝트가 **지금 어떻게 되어 있는지**를 설명하는 문서이며, 지속적으로 변경·개선·최신화되는 대상이다.

## 규칙

- 중앙 문서는 이 디렉토리 아래에 두고 SCM(git)으로 버전을 관리한다.
- 대부분의 문서는 마크다운이고, 필요에 따라 다른 형식의 문서도 둘 수 있다.
- 문서에는 현재 상태를 서술한다. "이번 작업에서 ~를 바꿨다" 같은 작업 이력은 `runs/` 아래의 작업 기록이 담당한다.
- 프로젝트의 사실이 달라지면 같은 작업 안에서 해당 문서를 최신화한다. SDD 워크플로우에서는 Plan 단계가 최신화 대상을 계획하고, Verification Gate를 통과한 뒤 Documentation 단계가 수행한다. 검증된 형상만 문서에 반영하기 위해 검증 뒤에 둔다.
- **이미 있는 문서만 최신화한다. 없는 문서를 새로 만들지 않는다.** 새 중앙 문서는 사람이 판단해 추가한다.

## `runs/`와의 차이

| | `docs/` (중앙 문서) | `runs/` (작업 기록) |
|---|---|---|
| 담는 내용 | 프로젝트의 현재 상태 | 각 SDD 작업이 어떻게 수행되었는지 |
| 변경 | 계속 최신화한다 | 작업이 끝나면 변경하지 않는다 |

## 범위 제외

- **GitHub 외 다른 소스의 실제 구현**(GitLab, Jira 등): 요청은 인터페이스와 GitHub 구현체까지다. 확장 가능성만 구조로 보장한다.
- **Webhook 등 push 방식 수집**: 요청이 Polling 방식을 명시했다.
- **`IssueWorker`의 Paseo workspace 생성·에이전트 실행 경로 변경**: 이번 작업은 루프의 Polling 단계만 다룬다. 배선상 불가피한 변경(주입 타입 등) 외에는 손대지 않는다.
- **폴링 실패에 대한 지수 백오프·서킷 브레이커**: 기존 Octokit throttle/retry 플러그인으로 충분하다고 보고 추가하지 않는다(EXPLORE A-07).
- **`since` 워터마크의 DB 영속화**: 기존과 동일하게 프로세스 메모리에 유지한다. 재기동 시 전체 재조회는 중복 필터(AC-10)가 흡수한다.
- **단위 테스트·통합 테스트 작성**: SDD 워크플로우 규칙에 따라 인수 테스트만 수행한다. 기존 `app/test/env.test.ts`는 회귀 방지용으로 유지만 한다.
